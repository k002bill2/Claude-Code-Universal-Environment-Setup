# Frontend Project Context

## Project Overview
- **Name**: My Web App
- **Tech Stack**: Next.js 15, React 19, TypeScript, Tailwind CSS
- **Architecture**: App Router, Server Components
- **State Management**: Zustand
- **Testing**: Vitest, React Testing Library, Playwright

## Development Guidelines
- Use functional components with TypeScript
- Implement proper error boundaries
- Follow accessibility guidelines (WCAG 2.1 AA)
- Optimize for Core Web Vitals
- Use Server Components where possible

## Common Tasks
1. **Create Component**: Generate in src/components with tests
2. **Add Route**: Create in app directory with layout
3. **API Integration**: Use server actions or route handlers
4. **Style Component**: Use Tailwind with component variants
