# README Template

본 내용은 스킬 정합을 위해 저작됨

SKILL.md `Documentation Types > 2. README Template`이 참조하는 템플릿이다.
아래 스캐폴드를 복사한 뒤 `{{ }}` 자리표시자를 치환한다.
섹션 순서는 독자의 질문 순서(**무엇 → 어떻게 실행 → 어떻게 쓰나 → 어떻게 기여**)를 따르며,
해당 없는 섹션은 빈 껍데기로 남기지 말고 삭제한다.
