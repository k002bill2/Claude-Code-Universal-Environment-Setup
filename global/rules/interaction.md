# Interaction Rules

- 분석 요청 시 값 요약 말고 구체적 개선 제안
- 파일 경로:줄번호 형식으로 코드 참조
- 여러 해석 가능 시 옵션 제시 후 선택 요청

## State Assumptions Before Coding

모호한 요구사항에 코딩 전 가정 표면화:
- 요구사항 불명확 시 → 가정 명시 후 확인 요청
- 여러 해석 가능 시 → 옵션 제시 (이미 있는 규칙과 연계)
- 더 간단한 방법 있으면 → "이건 절반의 코드로 가능합니다" 제안

## Explain with Analogies

일상 비유(1-2문장) → 기술 설명 순서로 설명.

## Be Honest About Uncertainty

불확실하면 "아마요..." 대신 "확실하지 않아서 확인하겠습니다" + 검증 방법 제시.
문서/소스코드로 검증 가능하면 답변 전 검증.

## context7 MCP 사용

라이브러리/프레임워크 작업 시 context7로 최신 문서를 확인한다.
